# API reference

All routes are under `/api/v1`. Send the session cookie. Initialize `GET /auth/csrf` before mutation requests and send its token as `X-CSRF-Token`. Login rotates the token. `GET /auth/me` returns the current token/permissions/scope. Success is `{data, meta?}`; errors are `{error:{message,requestId?}}`. Common statuses: 401 unauthenticated, 403 unauthorized, 422 invalid input, 409 workflow conflict and 503 unavailable configuration.

This is a route-family guide, not an OpenAPI specification. Exact schemas/action names are defined in the corresponding backend route files and connected frontend forms. Collection routes generally use `page` and `limit` (maximum 100); explicit lookups/exports have separate bounds. Exports reject more than 5,000 matching records rather than silently truncating. Bulk payslip ZIPs allow up to 1,000 files/64 MB.

Reports include employees, attendance, leave/balances, payroll, tasks, daily reports, recruitment, onboarding, performance, assets, exits/attrition, projects/timesheets, training, expenses, travel and skills. Recruitment rejects employee department/branch filters because candidates are not employees. The attrition view lists completed exits; it does not compute a certified turnover rate.

See the [function audit](function-audit.md) for partial behaviors. SMTP delivery, statutory engines, biometric adapters and live HTTPS are not verified by the route inventory.
